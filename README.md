# Real-World Retail Sales Analysis

## Thiranex Task
**Real-world Data Project (Finance, Health, or Retail)**

## Project Overview
This project analyzes the **Online Retail** dataset from the UCI Machine Learning Repository.

The dataset contains real transaction records from a UK-based online retailer between December 2010 and December 2011.

## Objectives
- Clean real-world transaction data
- Analyze sales trends
- Find top-selling products
- Analyze country-wise sales
- Analyze customer spending
- Visualize business patterns
- Generate conclusions from the data

## Dataset Source
UCI Machine Learning Repository - Online Retail Dataset

Dataset DOI: https://doi.org/10.24432/C5BW33

The notebook downloads the dataset automatically using the `ucimlrepo` package, so the large raw Excel file does not need to be stored in this GitHub repository.

## Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## How to Run

